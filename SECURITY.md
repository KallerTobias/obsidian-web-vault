# Security policy

obsidian-web-vault is a hobby project built with an AI coding agent (see the README). It has had an automated security audit, but no independent human audit.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's private vulnerability reporting instead: **Security** tab → **Report a vulnerability**. Include the version, your setup (proxy/tunnel) and steps to reproduce.

There is no bug bounty and no guaranteed response time, but reports are taken seriously and fixed as soon as possible.

## Supported versions

Only the latest release receives fixes.
